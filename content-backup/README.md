# Content backup

A copy of the website's content and photos, saved on October 21, 2026, so it isn't lost if the original hosting goes away. The live site doesn't read from this folder; it's here to rebuild or move the site.

| File | What's in it |
| --- | --- |
| `menu-items.json` | All 17 menu items: name, price, category, description, allergens, order, and which photo to use |
| `reviews.json` | The 9 customer reviews shown on the site |
| `faq.json` | 5 FAQ questions and answers (not currently shown on the site) |
| `gallery.json` | 8 gallery photos with captions (not currently shown on the site) |
| `social-links.json` | Instagram and TikTok links |
| `announcements.json` | The top-of-site announcement (currently turned off) |
| `photos/` | Every photo the site loads from its hosting |

Photos that aren't menu items:

- `f90f12d64_thestrawberryshoplogos_Mesadetrabajo12.png`: round logo in the header and footer
- `79980b498_strawberry_shop_logo_white_outline_medium.png`: browser tab icon
- `ea78651e4_42414B76-286D-4573-A6F0-C3431FA0BA1D.png`: gift card design
- `1325aa9bf_IMG_0916.jpeg`: photo on the Reviews page

Orders, catering requests and gift card requests aren't included, because they contain customers' personal details.
